# Mutants of native layout writes (audit/native-edit/tools/mutate.tcl;
# NATIVE-LAYOUT-WRITES.md, "Mutation testing"): each a deliberate bug in the
# field designators, the checks and the type (hir/layouts.tcl,
# hir/resolve.tcl, hir/types.tcl, hir/read.tcl), the registrations
# (core/binary.tcl), the Tcl reference implementation (core/binary.tcl),
# native lowering (native/lower.tcl) or the native runtime
# (native/src/runtime/nview.rs, ops.rs) -- the brief's defects first, one per
# layer where a layer implements the rule separately, then further ones.
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. A mutant editing native/src/ is a native
# mutant: mutate.tcl rebuilds the native backend for it. Lines starting with
# # outside an edit are comments.
