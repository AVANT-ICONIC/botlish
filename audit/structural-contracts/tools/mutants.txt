# Mutants of the verified callable contract boundary
# (audit/structural-contracts/tools/mutate.tcl;
# VERIFIED-CALLABLE-CONTRACT-BOUNDARY.md): the mutants the milestone brief
# names (item 52), each a deliberate bug in the completion analysis
# (hir/completions.tcl) or its one consumer outside it, ownership's error
# edges (hir/affine.tcl). Two families: the contract bound widened again (C3
# back, one transport or path at a time), and the bound trusted where nothing
# proved it (the boundary check, the possible errors of an untyped input,
# contravariant erasure) -- with the dangerous overcorrection, every
# unidentified call charged nothing, which the old soundness tests kill.
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. Lines starting with # outside an edit are
# comments.
