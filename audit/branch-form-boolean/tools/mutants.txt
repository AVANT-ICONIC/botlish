# Mutants of BRANCH-FORM-BOOLEAN-LOWERING.md (audit/branch-form-boolean/
# tools/mutate.tcl): the milestone's kill list, each a deliberate bug in the
# branch form of Boolean conditions -- an operand evaluated where its
# operator skips it, twice, or out of order, a `not` that does not swap, a
# condition lowered as a value after all, a value lowered as a condition, a
# release skipped -- in the shared rule (hir/condition.tcl), the Tcl
# compiler (compiler/compiler.tcl) or native lowering (native/lower.tcl).
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. Lines starting with # outside an edit
# are comments. Update a mutant's text when the code it mutates changes,
# keeping it a mutant of the same rule.

@@ tcl-and-evaluates-rhs-when-lhs-false the Tcl test of `a and b` joins its sides with the eager `&`: b runs even when a is false
## compiler/compiler.tcl

@@ tcl-or-evaluates-rhs-when-lhs-true the Tcl test of `a or b` joins its sides with the eager `|`: b runs even when a is true
